# antislop audit 002: Project Catalog + Header Button

**Date:** 2026-09-10
**Scope:** `/projects` catalog page, Navbar pill button, related wiring
**Mode:** 2 (After, audit of finished work)
**State:** remote `main` @ `7a2bca0`

Design Read (recorded): portfolio catalog for recruiters, existing brand language
(coral accent, Space Grotesk/JetBrains Mono, SpotlightCard, GSAP motion gate).
Dial: ENERGY 2 / RHYTHM 1 / MOTION 2.

All measurements taken in headless Chromium against built output, both themes,
mobile 375px. Method per finding is noted inline.

## Findings (ranked by tier)

### HIGH (Hard Gate)

1. **R-25 FAIL, light mode: muted text is 4.41:1.** `text-muted` on `bg-canvas`
   measures 4.41:1 at 18px (sub), 4.41:1 at 14px (card description), 4.41:1 at
   12px (card meta row). WCAG AA needs 4.5:1 for normal text. Off by 0.09.
   Affects: catalog sub, card description, meta row; also homepage (same token).
   Measured via computed styles + relative luminance math in-browser.

2. **R-25 FAIL, light mode: back link coral on cream is 3.12:1 at 14px.**
   `text-coral` (#e85d4a) on `bg-canvas` (#f4f4ef) needs 4.5:1 (14px is normal
   text). 3.12:1 fails. Affects: "Back to portfolio" link, "View full catalog"
   link on homepage (same color/size).

### MEDIUM (Purpose-Gate / Liveliness)

3. **R-14 pattern watch: six identical cards.** All 6 repo cards share size,
   padding, layout. Reasonable here (catalog of peers, rank order is not
   claimed), but hierarchy reason is not recorded anywhere. Acceptable with
   reason; flag for the record.

4. **R-08: arrow on every card.** ArrowUpRight on all 6 cards + back link arrow +
   catalog link arrow. Purpose: external-link affordance (card href is
   target=_blank). Passes purpose test, but dose is at the cap.

5. **R-27 note: error state shares the fallback state.** Loading (skeleton) and
   fallback (stale snapshot) exist. There is no distinct "API failed, showing
   snapshot" message. Data still renders, so the catalog never breaks; but the
   user cannot tell live from stale. Minor honesty gap, allowed by design
   decision in the spec.

### LOW (Quality Locks)

6. **R-02 legacy: em-dash in one visible UI string.** `FeaturedResearch.jsx`
   line 11: `desc: 'GReaT (LLM), CTGAN, SDG — 3,000 synthetic rows each'`.
   This is homepage research section, not catalog, but it is user-visible text
   with an em dash. Two code comments also contain em-dashes (motion.js local
   copy, Hero.jsx comments) but those are not UI text (R-02 scope: text).

7. **R-11: pill mix.** Nav pill buttons (full radius) + rounded-2xl cards +
   rounded-full chips on the same page. Documented rule exists in code review
   ("buttons full-pill, cards 16px, chips full") and is followed; passes with
   the rule written down.

  homepage; /projects route exists; social links real).

  density; pill is not the only touch target on its row).

- R-17/R-36: stars/dates live from GitHub API, fallback labeled as snapshot
  data in the data file; no invented statistics.
- R-27 loading: skeleton grid renders before data (verified offline run).
- C-5: all card content from real GitHub repos.
